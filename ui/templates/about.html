About Claim Checker

This is the sixth project created for use with the Grok system by Joseph Herrmann.

It’s a free tool designed to help detect potential bias in popular web stories and claims, providing confidence-weighted verdicts using Hugging Face models.

The goal is simple: promote clearer thinking and more balanced information in a noisy world.

Built with ❤️ using Flask and deployed on Render.
