Claim Assessment API

Status: online ✅

A free tool to detect potential bias in news stories or claims, with confidence-weighted verdicts.
Built with Flask + Hugging Face – your 6th Grok-related project!

Try it now


How to use the API

POST to /analyze with JSON: {"text": "your claim here"}

Example cURL:

curl -X POST https://claim-checker.onrender.com/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Example news headline or claim"}'
