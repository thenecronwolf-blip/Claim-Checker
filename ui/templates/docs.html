API Documentation

Endpoint: POST /analyze

Send JSON with a text field containing the claim or story.

curl -X POST https://claim-checker.onrender.com/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Your claim or news story here"}'

Example Response

{
  "result": {
    "bias_score": 0.75,
    "confidence": 0.82,
    "verdict": "Moderate potential bias detected"
  }
}
